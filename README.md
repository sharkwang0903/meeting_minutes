# 每日晨會紀錄系統

供內部晨會使用的簡易網頁工具，可填寫八位固定成員的昨日工作內容與會議重點，並預覽、下載統一格式的 A4 單頁 PDF。

## 功能

- 自動帶入本地當天日期，也可手動修改會議日期。
- 從固定成員名單選擇紀錄人。
- 填寫 Frank、Jethro、Shark、Roger、Henry、Albert、Jennifer、Annie 的工作內容。
- 勾選「未出席」時，PDF 顯示「未出席」；取消勾選後保留原先輸入內容。
- 新增、刪除重點事項，以主題與內容說明雙欄呈現。
- 預覽與下載共用同一份 PDF，檔名為 `YYYY-MM-DD_會議記錄.pdf`。
- 匯出前檢查內容高度，超出 A4 單頁時提醒精簡，不裁切文字。
- 自動儲存當日草稿，跨日後開始新的空白表單。
- 支援電腦與手機瀏覽。

## 使用方式

1. 將 `index.html`、`style.css`、`script.js` 放在同一個資料夾。
2. 使用 Chrome 或 Edge 開啟 `index.html`，也可透過 GitHub Pages 開啟網站。
3. 確認會議日期，並選擇紀錄人。
4. 填寫工作內容與重點事項，按「預覽 PDF」檢查，或按「下載 PDF」直接下載。

工作內容可以留白，不會自動視為未出席。完全空白的重點事項不會輸出；沒有任何重點事項時，PDF 顯示「無」。

如果瀏覽器無法內嵌顯示 PDF，可在預覽視窗切換「查看整頁影像」。

## 草稿儲存

草稿使用瀏覽器的 `localStorage`，只保留目前當日的資料，不提供歷史紀錄或跨裝置同步。

- 同一天使用同一個瀏覽器、相同網址重新開啟，可恢復草稿。
- 草稿依實際本地日期判斷是否跨日，與手動選擇的會議日期分開處理。
- 清除瀏覽器網站資料會刪除草稿；無痕模式或瀏覽器限制也可能影響保存。
- 本機檔案與 GitHub Pages 使用不同的儲存來源，草稿不會自動互通。
- 表單內容不會由本工具上傳至 GitHub 或其他伺服器。

## PDF 功能與網路需求

網站使用原生 HTML、CSS、JavaScript，無需 npm、開發伺服器、打包工具或後端。

PDF 使用 [html2canvas](https://html2canvas.hertzen.com/) 與 [jsPDF](https://github.com/parallax/jsPDF)，透過 CDN 載入，產生 PDF 時需要網路連線。主要來源為 `cdnjs.cloudflare.com`，載入失敗時會嘗試 `cdn.jsdelivr.net`。

中文與表格會先轉為頁面影像，再嵌入 PDF，以保留畫面字型與排版；PDF 內文因此不提供一般文字選取與搜尋。

如果出現函式庫載入錯誤，請確認網路可連線至上述來源，再重新整理頁面或重試。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 表單結構、操作按鈕與 PDF 預覽視窗 |
| `style.css` | 網站介面、響應式版面與 A4 排版樣式 |
| `script.js` | 成員設定、表單互動、草稿儲存與 PDF 產生 |
| `README.md` | 專案與使用說明 |

固定成員名單集中於 `script.js` 的 `MEMBERS` 常數，供開發者直接修改。

## GitHub Pages

將上述四個檔案放在儲存庫根目錄，於 GitHub 儲存庫的 **Settings → Pages** 啟用分支部署，選擇 `main` 分支與根目錄，即可透過部署後的網址使用。

原始會議紀錄的 Markdown、PDF 與參考 CSS 不需要上傳。請勿將含內部資訊的既有紀錄提交至公開儲存庫。
